What it does

A calm, unified view built for one person — the operator.

Unified view

Reads events from connected Google Calendar and Microsoft 365 accounts and displays them together in one combined dashboard.

Live sync

Calendars are kept in sync in the background so the dashboard always reflects the latest schedule.

Companion feed

A token-protected JSON feed lets the operator's own companion clients — like a wall-mounted display — read the combined calendar.

External events API

A simple HTTP API accepts external events pushed in from other tools, shown alongside connected calendar data.

Who it's for

This is a personal project, not a public or commercial service. It's used only by its operator and is not intended for sign-ups from the general public.

Sign-in is required to view or manage any calendar data — nothing here is browsable without authentication.
