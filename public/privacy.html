Privacy Policy - nextUp Calendar

Last updated: 11 September 2026

nextUp Calendar is a self-hosted, personal calendar dashboard operated by Mark Beets for his own private use. It is not offered as a public or commercial service.

What data it accesses

nextUp Calendar connects to Google Calendar and Microsoft 365 Calendar accounts that the operator explicitly authorises. Using the permissions granted, it reads calendar event data (such as event titles, times, and locations) from those accounts in order to display a combined view in a single web dashboard.

What data it stores

Calendar event data retrieved from connected accounts is cached locally on the operator's own self-hosted server, for the sole purpose of displaying and serving the combined calendar view and the JSON feed described below. No calendar data is shared with, sold to, or processed by any third party.

Companion feed and API

nextUp Calendar exposes a token-protected JSON feed so the operator's own companion clients (for example, dashboard displays) can read the combined calendar data. Access to this feed requires a private access token; it is not publicly accessible. A simple HTTP API also allows the operator to push external events into the local cache for display alongside connected calendar data.

Data sharing

No data accessed through Google Calendar or Microsoft 365 is shared with any third party. Data does not leave the operator's own infrastructure except as needed to communicate with the Google Calendar and Microsoft Graph APIs to retrieve the operator's own calendar data.

Data retention and deletion

Cached calendar data is retained only as needed to serve the dashboard and feed, and is refreshed/overwritten on each sync. Access can be revoked at any time via the connected Google Account's or Microsoft 365 account's third-party app permissions, which stops all further data access.
